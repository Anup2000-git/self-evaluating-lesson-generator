title: Where RAG is used
source: Microsoft Learn, "Retrieval Augmented Generation (RAG) in Azure AI Search"; curated summary of common, publicly described RAG applications.
---

## Help-desk and customer support assistants

Companies use RAG so that a support chatbot answers from the company's own help pages, product manuals and policies, instead of guessing. The answer can link to the help page it used.

## Assistants for employees

Organisations build internal assistants that answer staff questions from HR policies, rules and internal documents, for example "How many days of leave do I get?".

## Education

A college or school can build a chatbot that answers student questions from its notices, timetable and syllabus, for example "When is the last date to submit the exam form?".

## Searching large document collections

Professionals such as lawyers, doctors and researchers use RAG-based tools to ask questions over large collections of documents and get answers that point to the exact source documents.

## AI search with sources

Some web search tools use a similar idea: they search the web for relevant pages and then use an LLM to write an answer from those pages, showing links to the sources.
